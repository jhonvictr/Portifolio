# Developer Portfolio

Portfolio em React + Vite, com a estilização e os assets gerados pelo Figma preservados.

## Executar localmente

Requer Node.js 20 ou superior.

```bash
npm install
npm run dev
```

Depois, abra a URL exibida pelo Vite no navegador. Para gerar a versão de produção:

```bash
npm run build
npm run preview
```

Também é possível iniciar o servidor com `npm start`.
